# Step 9: Build Your Command Center Dashboard

## Goal

Turn the starter page into a project-management dashboard based on your AI+Design Studio Command Center.

This is a beginning version. It does not need to be polished or complete.

## What to Include

Use the Command Center sections you already have. Keep all seven sections or keep only the sections that make sense for your current work.

- Project Identity Card
- Inquiry Brief
- Source Starter List
- Project Brief / Weekly Roadmap
- Prompt Log
- Experiment Log
- Links / Workspace Board

## Suggested AI Tool Prompt

Open `Documents/GitHub/github-startup` in Antigravity, Codex, or Claude Code and start with:

```text
Interview me about my AI+Design Studio Command Center. Then help me revise this starter page into a clear project-management dashboard based on the sections I already have. Before changing files, make a short plan for me to review.
```

After you approve the plan, let your AI coding tool update the files.

## Push the Update

When the dashboard is ready:

1. Open GitHub Desktop.
2. Review the changed files.
3. Write a summary such as `Build Command Center dashboard`.
4. Click **Commit to main**.
5. Click **Push origin**.
6. Refresh your GitHub Pages link after a few minutes.

## Final Submission Checklist

- [ ] My dashboard is based on my Command Center.
- [ ] I committed and pushed with GitHub Desktop.
- [ ] My GitHub Pages link shows the updated dashboard.
- [ ] I have my GitHub repository link.
- [ ] I submitted the GitHub Pages link in Canvas.
- [ ] I have a screenshot of GitHub Desktop after push, if my instructor asks for it.
