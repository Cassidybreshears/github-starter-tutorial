# Step 7: Publish with GitHub Pages

## Goal

Turn your repository into a live static website.

## Instructions

1. On GitHub, open your `github-startup` repository.
2. Click **Settings**.
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Set the branch to `main`.
6. Set the folder to `/ (root)`.
7. Click **Save**.
8. Wait a few minutes.
9. Open the GitHub Pages link when GitHub shows it.

Your link will look something like:

`https://your-username.github.io/github-startup/`

## Checklist

- [ ] GitHub Pages is enabled.
- [ ] The source is `main` and `/ (root)`.
- [ ] I opened my live GitHub Pages link.
- [ ] The live page shows my setup change.
