# Step 7: Commit and Push from GitHub Desktop

## Goal

Save your AI-built changes and publish them to the live site.

## Instructions

1. Open GitHub Desktop.
2. Make sure the current repository is `github-startup`.
3. Look at the changed files list on the left. Click a file to see what changed.
4. In the **Summary** box at the bottom-left, write a short message like `Build Command Center dashboard`.
5. Click **Commit to main**.
6. Click **Push origin** (appears after you commit).
7. Wait 1–2 minutes, then refresh your GitHub Pages link.
8. Confirm your changes are live.

## You're done

Your workflow from now on:

1. Make changes in your AI coding tool (or directly in the files)
2. Open GitHub Desktop
3. Write a summary and click **Commit to main**
4. Click **Push origin**
5. Your live page updates automatically

## Checklist

- [ ] I committed my changes in GitHub Desktop.
- [ ] I pushed to GitHub.
- [ ] My GitHub Pages link shows the updated dashboard.
- [ ] I have my GitHub repo link and my live site link ready to submit.
