# Step 6: Open the Local Folder in Your AI Coding Tool

## Goal

Open the same project folder in Antigravity, Codex, or Claude Code so your AI tool can see your files.

## Instructions

1. Open the AI coding tool you chose.
2. Choose the option to open, add, or select a folder.
3. Select this folder:

   `Documents/GitHub/github-startup`

4. Confirm the tool can see files such as:

   - `README.md`
   - `index.html`
   - `style.css`

5. Ask the tool to help you make a small setup check. For example:

   "In `index.html`, replace `Your Project Title` with my name and a short project title. Do not change anything else."

6. Review the change before moving on.

## Tool Notes

- **Antigravity:** Open or add the `github-startup` folder as your project folder.
- **Codex:** Open <https://chatgpt.com/codex/>, select `Documents/GitHub/github-startup`, then ask it to list files.
- **Claude Code:** Open the Claude Code overview at <https://code.claude.com/docs/en/overview>, select `Documents/GitHub/github-startup`, then ask it to list files. If your Claude Code setup requires Terminal and you are not comfortable with Terminal, use Antigravity or Codex for now.

## Checklist

- [ ] My AI coding tool is open.
- [ ] It is using `Documents/GitHub/github-startup`.
- [ ] It can see `README.md`, `index.html`, and `style.css`.
- [ ] I made one small setup change.
