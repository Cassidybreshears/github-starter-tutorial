# Step 3: Install GitHub Desktop and Choose an AI Coding Tool

## Goal

Install GitHub Desktop and choose the AI coding tool you will use.

## Instructions

1. Install GitHub Desktop: <https://desktop.github.com/>
2. Choose one AI coding tool:

   - Antigravity: <https://antigravity.google/>
   - Codex: <https://chatgpt.com/codex/>
   - Claude Code: <https://code.claude.com/docs/en/overview>

3. Install or open the tool you chose. Use the desktop app or the VS Code version if that is what your instructor assigned.
4. In Finder or File Explorer, open your **Documents** folder.
5. Create a folder named `GitHub`.

This folder is where your downloaded GitHub projects will live.

## Checklist

- [ ] GitHub Desktop is installed.
- [ ] I chose Antigravity, Codex, or Claude Code.
- [ ] My chosen AI coding tool is installed or available.
- [ ] I created `Documents/GitHub`.
