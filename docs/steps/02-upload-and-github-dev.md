# Step 3: Upload Files and Edit with github.dev

## Goal

Upload your project files to your repo, then make your first edit — all in the browser, nothing to install.

## Instructions

### Part A: Upload your files

1. On GitHub, open your own `github-startup` repository.
2. Click the **Add file** button (near the green Code button).
3. Choose **Upload files**.
4. Open Finder or File Explorer on your computer and find the project folder you want to upload (the one with `command-center.html` and any image folders).
5. Drag the files and folders from your computer onto the GitHub upload area.
6. Scroll down, write a message like `Upload command center files`.
7. Click **Commit changes**.

### Part B: Open the web editor

1. In your repo, press the **`.`** (period / dot) key on your keyboard.
2. A VS Code-like editor opens in your browser tab. This is **github.dev** — no install needed.

### Part C: Make a change

1. In the file list on the left, click a file to open it (try `index.html`).
2. Find your name or project title and change it to something personal.
3. You should see a blue dot on the file tab showing it has unsaved changes.

### Part D: Commit your change

1. Click the **branch icon** on the left sidebar (3rd from top — looks like a fork in a road).
2. You'll see your changed file listed under **Changes**.
3. In the text box that says "Message", type something like `Update project title`.
4. Click the blue **Commit & Push** button.

That's it. Your change is saved to GitHub.

## Checklist

- [ ] I uploaded my project files to the repo.
- [ ] I pressed `.` to open github.dev.
- [ ] I opened a file and made a change.
- [ ] I committed and pushed the change.
- [ ] I can see my changes on the GitHub repo page.
