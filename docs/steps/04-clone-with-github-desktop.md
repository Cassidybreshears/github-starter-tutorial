# Step 5: Clone Your Repo with GitHub Desktop

## Goal

Copy your online `github-startup` repository to your computer.

## Instructions

1. On GitHub, open your own `github-startup` repository.
2. Click the green **Code** button.
3. Choose **Open with GitHub Desktop**.
4. When GitHub Desktop opens, check the **Local Path**.
5. Choose your `Documents/GitHub` folder.
6. Click **Clone**.

Your finished local folder should be:

`Documents/GitHub/github-startup`

## Checklist

- [ ] I opened my own `github-startup` repository on GitHub.
- [ ] I used **Open with GitHub Desktop**.
- [ ] I cloned it into `Documents/GitHub`.
- [ ] GitHub Desktop shows `github-startup` as the current repository.
