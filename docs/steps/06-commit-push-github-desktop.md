# Step 7: Commit and Push with GitHub Desktop

## Goal

Save your local change as a commit and upload it to GitHub.

## Instructions

1. Open GitHub Desktop.
2. Make sure the current repository is `github-startup`.
3. Look at the changed files list.
4. Click a changed file to preview what changed.
5. In the **Summary** box, write a short message such as:

   `Setup check`

6. Click **Commit to main**.
7. Click **Push origin**.
8. Open your `github-startup` repository on GitHub.
9. Confirm the change appears online.

## Checklist

- [ ] GitHub Desktop showed my changed file.
- [ ] I wrote a short commit summary.
- [ ] I clicked **Commit to main**.
- [ ] I clicked **Push origin**.
- [ ] I confirmed the pushed change on GitHub.
