# Step 6: Open in Your AI Coding Tool and Build Your Dashboard

## Goal

Open your local project folder in an AI coding tool and use it to build your Command Center dashboard.

## Instructions

### Part A: Open the folder in your AI tool

1. Open your AI coding tool:

   - **Antigravity** — open the app, add your `Documents/GitHub/github-startup` folder
   - **Codex** — go to https://chatgpt.com/codex/, select `Documents/GitHub/github-startup`
   - **Claude Code** — open the app and select `Documents/GitHub/github-startup`

2. Confirm the tool can see your files (you should see `index.html`, `style.css`, `README.md`, and any files you uploaded).

### Part B: Build your dashboard

Use your AI coding tool to build a Command Center dashboard. Start with something like:

```
Interview me about my project. Then help me turn the starter page (index.html)
into a project dashboard with these sections:

- Project title and research question
- Key sources and research notes
- Experiment and prompt logs
- Workspace links

Make it look clean and organized. Show me a plan before you change anything.
```

Let the AI help you improve the page. You can go back and forth — ask for changes, try different layouts, add your own content.

### Part C: Preview your changes

1. In Finder or File Explorer, open `Documents/GitHub/github-startup`.
2. Double-click `index.html` — it will open in your web browser.
3. You can see your local changes before they go live.

## Tool notes

- **Antigravity:** Open or add the `github-startup` folder as your project.
- **Codex:** Open https://chatgpt.com/codex/, select `Documents/GitHub/github-startup`.
- **Claude Code:** Open the app, select `Documents/GitHub/github-startup`.

## Checklist

- [ ] My AI coding tool is open and can see `Documents/GitHub/github-startup`.
- [ ] I used the AI to build my Command Center dashboard.
- [ ] I previewed my changes locally.
- [ ] The dashboard has my project info, research, logs, and links.
