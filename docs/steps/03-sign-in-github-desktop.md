# Step 4: Sign In to GitHub Desktop

## Goal

Connect GitHub Desktop to your GitHub account.

## Instructions

1. Open GitHub Desktop.
2. Choose **Sign in to GitHub.com**.
3. Continue in your browser if GitHub Desktop sends you there.
4. Approve the sign-in.
5. Return to GitHub Desktop.

If GitHub Desktop asks how you plan to use Git, choose the normal/default options. You do not need Terminal for this tutorial.

## Checklist

- [ ] GitHub Desktop is open.
- [ ] GitHub Desktop is signed in to my GitHub account.
- [ ] I can see my GitHub account name inside GitHub Desktop.
